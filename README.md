# iOS Rule Script

适用于 Quantumult X 和 Surge 的规则、复写及脚本整理仓库。

---

## 项目结构

- `rule/`：分流规则目录
- `rewrite/`：复写规则目录
- `script/`：实用脚本集合
- `README.md`：项目说明文档
